> Both networks connect you to the **DeFiMetaChain Mainnet** (Chain ID 1130).

## 💻 Desktop – Add Network

### Step 1 – Open MetaMask

Click the 🦊 **fox icon** in the top right of your browser.

> ℹ️ If MetaMask is locked, enter your password first.

### Step 2 – Open Network dropdown

Click on Menu and in Settings you will find Networks.

### Step 3 – Add Network

Click **"Add Network"** → then click **"Add Network Manually"**.

### Step 4 – Enter Network Details

Fill in the form with the following details.

**Option A – DeFiMetaChain (mydefichain):**

| Field | Value |
|-------|-------|
| Network Name | `DeFiMetaChain` |
| RPC URL | `https://dmc.mydefichain.com/mainnet` |
| Chain ID | `1130` |
| Currency Symbol | `DFI` |
| Block Explorer | `https://mainnet-dmc.mydefichain.com:8441` |

**Option B – DeFiMetaChain (jellyfish):**

| Field | Value |
|-------|-------|
| Network Name | `DeFiMetaChain` |
| RPC URL | `https://eth.mainnet.ocean.jellyfishsdk.com` |
| Chain ID | `1130` |
| Currency Symbol | `DFI` |
| Block Explorer | `https://blockscout.mainnet.ocean.jellyfishsdk.com` |

> ⚠️ **Important:** Enter the details exactly as shown above – typos may cause the network to not work!

### Step 5 – Save

Click **"Save"**. MetaMask will verify the details and automatically switch to the new network.

> ✅ You will now see **"DeFiMetaChain"** at the top of MetaMask – the network is active!

## 🔄 Switching Between Networks

To switch networks at any time:

1. Click / tap the **network name** at the top
2. Select the desired network from the list
3. MetaMask switches instantly

> 💡 You can add **both DeFiMetaChain networks** and switch between them at any time. Your wallet address always stays the same.
